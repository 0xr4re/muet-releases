# muet releases

This public repository contains signed, notarized releases of [muet](https://muet.app), a private meeting assistant for macOS.

- [Download the latest version](https://github.com/0xr4re/muet-releases/releases/latest/download/muet.dmg)
- [View all releases](https://github.com/0xr4re/muet-releases/releases)
- [Sparkle update feed](https://0xr4re.github.io/muet-releases/appcast.xml)

The application source is private. Release ZIPs are signed for Sparkle, and DMGs are signed with Developer ID and notarized by Apple before publication.
